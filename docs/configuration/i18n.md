# Languages

One config, N languages. No duplicate files.

## Declaring locales

```yaml
# site.yaml
locales: [fr, en]
```

The first entry is the default: it is the fallback for missing translations
and for visitors whose browser language is not served. Locale codes appear in
URLs (`/fr/`, `/en/`) and match browser languages by base tag (`fr-CA`
visitors get `fr`).

## How a visitor gets a language

1. Their saved choice. Only the header switcher sets the one-year cookie
   (its links carry `?choose`); a plain visit never does, so a visitor who
   changes their browser language is followed until they explicitly pick
   one.
2. Otherwise the browser's `Accept-Language`.
3. Otherwise the default locale.

`/` redirects accordingly, and the sitemap lists every locale of every
page, so search engines index each language separately.

## Translated fields

Every field typed _text_ in the [reference](../reference.md) accepts either
form: service names, descriptions and details, the tagline, the welcome
note, link and footer labels, hosted-page titles and bodies, category
names, UI strings.

```yaml
name: PDF toolbox                                # every locale
name: { fr: Boîte à outils PDF, en: PDF toolbox } # per locale
```

A plain string applies to every locale. A per-locale map resolves to the
visitor's locale, then the default locale, then any value rather than
nothing.

## UI strings

The interface text ships built in for **English, French, German, Spanish,
Italian, Dutch and Portuguese**; a regional code finds its base language
(`pt-BR` uses the `pt` table). Any other locale falls back to English until
you override it: `strings` in `site.yaml` accepts any locale:

```yaml
# site.yaml: cairn in Polish
locales: [pl]
strings:
  nav.skip: Przejdź do treści
  search.label: Szukaj
  search.placeholder: Szukaj narzędzia…
  search.empty: Brak wyników. Spróbuj innego słowa.
  cat.other: Inne
  card.more: Dowiedz się więcej
  detail.open: Otwórz narzędzie
  detail.back: Wstecz
```

Missing your language? Adding it to cairn itself is a small, welcome pull
request: see [Add your language](../../CONTRIBUTING.md#add-your-language).

A word on quality: French and English are written by someone who speaks them.
The other five are careful but unreviewed, and interface words are exactly
where a slightly-off translation grates. If one of them is your language and a
string reads wrong, correcting it is a one-line pull request and genuinely
welcome.

## Right-to-left languages

Set a right-to-left locale and the page turns around on its own: cairn writes
`dir="rtl"` on `<html>` for Arabic, Hebrew, Persian, Urdu and the others, and
the stylesheet is written with logical properties, so the whole layout mirrors
rather than being patched side by side.

```yaml
# site.yaml
locales: [ar, en]
```

The interface text is a separate matter: none of the seven built-in languages
is right-to-left, so the chrome falls back to English until you translate it
with `strings` above. The direction works either way; the words are yours.

| Key                  | English default               | Where                                            |
| -------------------- | ----------------------------- | ------------------------------------------------ |
| `nav.skip`           | Skip to content               | keyboard skip link                               |
| `nav.languages`      | Language                      | switcher label (a11y)                            |
| `nav.toc`            | Categories                    | category trail label (a11y)                      |
| `nav.links`          | Links                         | header nav row label (a11y)                      |
| `nav.theme`          | Theme                         | theme toggle label (a11y)                        |
| `about.dismiss`      | Dismiss                       | welcome note close button                        |
| `foot.powered`       | powered by                    | footer credit, before "cairn"                    |
| `search.label`       | Search                        | search input label (a11y)                        |
| `search.placeholder` | Search for a tool…            | search input                                     |
| `search.empty`       | No results. Try another word. | empty search state                               |
| `search.one`         | 1 result                      | screen-reader count, singular                    |
| `search.many`        | %d results                    | screen-reader count, plural (`%d` is the number) |
| `cat.other`          | Other                         | implicit category                                |
| `card.more`          | Learn more                    | card link to detail page                         |
| `detail.open`        | Open the tool                 | detail page button                               |
| `detail.back`        | Back                          | detail page back link                            |
| `status.up`          | Online                        | status pill label                                |
| `status.down`        | Offline                       | status pill label                                |
| `status.unknown`     | Unknown                       | pill label before Gatus answers                  |
| `status.link`        | view status                   | status pill link hint (a11y)                     |

A partial override only applies to the locales it names; the built-ins fill
the rest.
